# Grade Calculator

A beginner-friendly Grade Calculator built using Python.

## Features

- Enter marks for multiple subjects
- Calculate total marks and percentage
- Assign a grade based on percentage
- Display PASS or FAIL status
- Validate marks between 0 and 100
- Generate a subject-wise grade report

## Technologies Used

- Python 3
- Functions
- Conditional statements
- Loops
- Lists and tuples
- Exception handling

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open Terminal in the project folder.
4. Run the following command:

   `python3 main.py`

## Grading Scale

| Percentage | Grade |
|---|---|
| 90–100 | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| 50–59.99 | D |
| 40–49.99 | E |
| Below 40 | F |

A student must score at least 40 marks in every subject to pass.

*Note: This is a practice grading scale, not an official university grading policy.*

## Learning Outcomes

This project demonstrates basic Python programming, user input, calculations, loops, functions, validation, and conditional logic.
